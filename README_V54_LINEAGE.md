# Planetary Restoration Model Version 54 — Lineage Recovery

Version 54 keeps the Version 53.1 Earth-system/climate/CDR core intact and restores the historical modules that disappeared from the V53.x release wrapper without an explicit scientific withdrawal.

## What is restored

- seaweed SAF / HTL and concentrated-solar process heat
- the later v19 physical grid/drone seaweed harvester
- food-grade seaweed
- wastewater and food-waste methane/CHP
- N/P/K nutrient loops and the older gross seaweed nutrient-capture screen
- tidal energy
- detailed maritime decarbonization
- storage technology portfolio and firm-clean option screen
- climate/geopolitical/pandemic/deployment shock suite
- tree natural-capital reserve, growth-dividend and permanence architecture
- national genesis allocation and country contribution equalizer
- parallel settlement / Bitcoin leakage and sanctions-governance sensitivities
- dollar-transition context and no-new-burden/protected-payment rules
- food and universal-basic-health resource budgets
- distributed AI/data-center banking transition, the 20,000-site network and Cella demonstration archetype
- workforce transition and cross-border equalizer funding
- current V53.1 water, seaweed, nutrient, plastics, banking and social/ecological screens, which existed in source but were omitted from the release wrapper

## Critical energy reconciliation rule

Version 53.1 carries an **86,181.327 TWh/yr externally supplied, undecomposed pre-CDR electricity screen**. Several recovered historical modules are components of that total or possible supplies against it. Version 54 therefore restores them in `RECONCILE_ONLY` mode and makes **zero adjustment to the climate headline** until that external total is decomposed by sector/technology. This prevents double counting.

Examples of restored decomposition candidates include the older shipping electricity screen, seaweed-SAF process electricity, grid-harvester power, wastewater/food-waste generation and tidal generation.

## Superseded results are not resurrected

The older model's historical CO2 restoration dates and its historical zero-new-nuclear central adequacy result are preserved only as lineage. They do **not** replace the current Version 53.1 Earth-system and synthetic 8760-hour adequacy results. The V53.1 external calibrated/constrained FaIR and archived OSCAR validation gate also remains in force.

## Files

- `Planetary_Restoration_Model_V54.xlsx` — V53.1 released workbook plus recovered module sheets and a lineage/reconciliation dashboard.
- `planetary_restoration_model_v54.py` — executable Version 54 source; defaults to the 700-draw advanced ensemble.
- `data/` — recovered module CSV/JSON exports.
- `previous_version/` — the V53.1 source/workbook used as the core.
- `legacy_reference/` — historical workbooks and the grid-harvester source used to recover the dropped modules.

Run with `RUN_MODEL.bat` on Windows or `./RUN_MODEL.sh` on macOS/Linux. For a faster validation-only run, use `--no-write --ensemble-samples 20`.
