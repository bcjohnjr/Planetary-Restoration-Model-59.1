# Benchmark extension beyond 2183

The frozen V53.1 canonical trajectory ends in 2183 because the internal release exports a 30-year post-target maintenance window.

For external simple-climate-model comparison through 2400, this bundle creates
`validation_input/external_validation_net_co2_trajectory_extended_to_2400.csv`
by holding the **2183 net CO2 flux constant** from 2184 through 2400.

This is a transparent validation-extension assumption, not a new V53.1 forecast. Report external-model
crossing dates both (a) within the original 2026–2183 window and (b) under this constant-flux extension.
Do not silently merge the extension into the planetary-restoration model.
